# Earth and Mars Field Props

These ten field objects replace the former procedural rectangles and triangles
used during campaign levels.

## Earth

- Robotic ball cart
- Robotic hydration station
- Holographic tactics console
- Deployable training-cone barricade
- Reinforced equipment trunk

## Mars

- Alien oxygen pod
- Armored meteor salvage crate
- Alien holographic gate
- Crystal barricade
- Artifact vault

The source images were generated individually with the built-in image-generation
workflow. Each prompt referenced its matching live arena and an existing
Earth robot or Mars alien, specified the shared elevated gameplay camera,
world-specific key/rim/bounce lighting, phone-scale silhouette, and a flat
green chroma background. `ChromaSource` preserves those originals;
`Processed` contains the transparent working renders. The asset catalog
contains trimmed, padded 512-by-512 production sprites.
